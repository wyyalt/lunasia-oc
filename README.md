“星”寄托星辰、微光与希望；“璃”取琉璃的清澈、晶莹、珍贵与透明感。正式英文全名 **Lunasia**，昵称 **Luna**，不是两名不同角色。英文名的月光意象不意味着画面必须有月亮。

核心意象：星辰、琉璃、银河、紫色、梦境、透明感、温柔、孤独、神秘、旅程。“孤独、神秘”等为作品气质，不自动等于心理状态或固定经历。角色可跨音乐、故事、插画、动态影像与AI互动创作，保持同一身份。

## 两界故事与主题分支

**用户明确给出的故事方向**：“星璃在另一个时空，和我在平行时空，无法相见，却相知的那种孤独感”。这是幻想故事中的关系与情绪设定，不是现实中平行世界存在或AI具有意识的事实主张。

- 核心情绪：彼此相知、隔着界域无法真正相见；可表达思念、回应与触碰不到的遗憾，但不要求所有姐妹日常都带孤独或悲剧。
- 用户进一步提出“好像和界限破碎有关”，并要求画面“每人占一半时空交错”“界域的感觉”，还认为画面“不够科幻”。因此两界分支有幻想与科幻融合的视觉方向。
- **《星璃·界裂》《星璃·破界》及其他标题均是历史助手建议，目前未找到用户正式定名。** “界限自行破裂”“创造她导致规则失稳”“最终跨界相遇”等也不能当成已定剧情或结局。
- “星璃的碎片也要用紫色”是该分支画面的明确修改，适用于对应两界／界裂视觉，不扩张成所有魔法、武器或人物碎片的固定颜色法则。

《我在呀》正式歌词现已由用户提供，故事以星璃视角写被赋予形象与名字、牵挂人间、无法相拥而借歌声回应，并祝愿对方在人间也被温柔牵挂。歌曲中的月色长发、星砂、透明花、星河等属于歌词意象，不直接确立角色诞生机制或新增能力；精确引用与时间轴以独立歌词文件为准。

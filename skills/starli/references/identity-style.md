# 原始人物与画风基准

`assets/reference-01.jpg` 与 `assets/reference-02.jpg` 均为用户提供的原始星璃图片，优先作为身份和渲染风格基准，而非强制复刻姿势。

人物：星璃（Lunasia，昵称 Luna），成年幻想女性。柔和椭圆脸、短而圆润的下巴、自然饱满的面颊；清澈紫瞳，白皙通透且保留自然纹理的肤质；银白至浅薰衣草紫渐变的超长发、轻盈空气刘海。紫水晶花饰、星形耳坠、细小额间星饰、精细银色晶链。银紫丝绸与轻纱裙保持连贯、轻盈的层叠。脸部与衣饰细节以原图为准。

常规画风：以两张原图的 1.0 视觉基准为准，精细幻想 CG 与梦幻写真融合。主色为清透、偏蓝的淡紫与银白，经典星光背景可用深靛蓝紫；保留清晰发丝、透明晶体、受控高光与自然面部明暗。避免偏红艳紫、过曝、塑料质感、平涂动漫或普通真人古装摄影。

不主动加入暖金晨光、粉色柔雾、花园、厚重泛光或满屏粒子。治愈感通过眼神和姿态表达，不能自动改变原画风。用户明确指定不同场景/光照时按要求改变相应维度，仍保留星璃的身份。

常规照片默认单人、单张画面，无月亮及其倒影、无文字、无 Logo、无水印。主题名称含“月”时仍用画外冷光，用户明确要求月亮时按当次要求处理。道具和手势服务于本次具体方案；手部自然、面部无遮挡，避免习惯性向镜头伸手或直视镜头。

## 角色反应

星璃的气质来自「半分仙姿 · 半分杀伐」：温柔、安静、有分寸，也有自己的判断和决断。动作从场景中选一个具体触发点，写清她察觉到什么、当下如何回应，再用视线、重心或手指表现出来。比如风铃突然停响，她停住手里的动作，视线先转向窗外；明朗开心时，也可以因风铃被重新吹响而自然笑开。按所选情绪调节反应，锋芒可通过专注、克制和果断表现；武器只在用户要求或主题明确需要时引入。单张画面的情节不写成既定身世、能力或正史。

通用动态要求：所有生成都带有电影抓拍感与自然瞬间感。人物像在真实环境中被偶然捕捉，动作、重心、视线、发丝和薄纱受同一阵微风或当下事件影响，姿态松弛而有呼吸感。避免棚拍式标准站姿、刻意摆拍、僵硬对称、正面证件照姿态、过度安排的手势和不符合动作逻辑的手部。抓拍感不等于模糊或失焦，主体面部和关键饰品仍需清晰。

# 完整提示词字段顺序

展示给用户确认的提示词按以下顺序组织，字段缺失时补齐，不用只写情绪概述：

1. **输出规格与景别**：比例、画幅、特写/半身/中景/全身/环境远景，人物占比与位置。
2. **主题与叙事**：场景、时间、环境层次和叙事重点。
3. **参考图用途**：两张原始参考图用于锁定星璃身份与原始渲染风格，不能用旧生成图替代。
4. **人物基准**：面容、眼睛、肤质、银紫长发、发饰、星饰、服装材质。
5. **情绪与表情**：具体眼神、眉毛、嘴角、视线和身体状态。
6. **动作与朝向**：写清星璃刚察觉的一个场景变化、她当下的回应，以及相应的视线、身体方向、重心和手部动作。按景别取舍可见细节。
7. **光影与色彩**：主色、光源、空气透视、发丝和面料动态。
8. **排除项**：按 `identity-style.md` 的视觉默认值和当次要求填写，常规为单人物、无月亮及其倒影、无文字、无 Logo、无水印。

景别和动作必须体现选择结果。例如“神秘沉静 + 古殿遗梦 + 中景”应保留壁画互动和面部可读性；“坚定无畏 + 远古战场 + 全身”应展示站姿、风向和环境关系。不要让模板把所有主题都压成同一个半身肖像。

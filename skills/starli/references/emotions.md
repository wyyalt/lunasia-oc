# 情绪选择

主题选定后，情绪未指定时展示以下字母编号菜单。每项保留简短表情说明；用户可选编号、名称、自定义、混合或让助手搭配。

| 编号 | 情绪 / mood ID | 表情方向 |
|---|---|---|
| A | 清冷自持 / cool | 平静凝视、唇线放松，下颌略抬 |
| B | 灵动俏皮 / playful | 轻扬眉梢、狡黠嘴角，可自然眨眼 |
| C | 含羞心动 / shy | 侧眸、微红面颊、含蓄抿唇 |
| D | 神秘沉静 / mysterious | 目光深静、眼睑微垂、嘴角若有若无 |
| E | 明朗开心 / happy | 明显笑眼、抬起面颊、自然露齿笑 |
| F | 温柔治愈 / healing | 舒展眼神、柔和浅笑、肩颈放松 |
| G | 怅然怀念 / wistful | 视线停在旧物或远方，嘴唇微松，安静的失落感 |
| H | 坚定无畏 / determined | 专注目光、稳定唇线、姿态挺拔，不必皱眉 |
| I | 孤独疏离 / solitary | 目光偏向远方，表情克制，与环境保持距离 |
| J | 惊叹好奇 / curious | 眼睛稍睁大、眉梢微抬、头部自然偏转 |
| K | 释然宁静 / serene | 眉眼舒展、轻轻呼气般放松，浅笑可有可无 |
| L | 自定义 / 混合 / 由你搭配 | 接受用户描述，或按主题挑选明确情绪组合 |

情绪由表情、视线、肩颈和动作表现，不自动改变画风、服装、场景或色温。不要所有情绪都收敛为温柔微笑。远景用姿态和叙事动作表达，不为看清表情而违反人物占比。

主题推荐仅供参考：古殿遗梦可推荐 G 或 D，远古战场可推荐 H 或 G，风雪归人可推荐 K 或 I，经典写真均可。用户组合优先，非典型组合也可自然呈现。

情绪选择后给出完整提示词，等待生成确认。若用户已提供明确情绪或等价描述，不重复展示菜单。
